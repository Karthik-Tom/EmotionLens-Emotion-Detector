# EmotionLens: Emotion Detector from Text

## Project Overview
EmotionLens is a Team 13 AI project that predicts the dominant emotion in a short text message using a PyTorch Transformer model.

## Dataset
- **Source:** [DAIR-AI Emotion Dataset](https://huggingface.co/datasets/dair-ai/emotion)
- **Configuration:** `split`
- **Total samples:** 20,000
- **Training samples:** 16,000
- **Validation samples:** 2,000
- **Test samples:** 2,000

## Emotion Categories
- Sadness
- Joy
- Love
- Anger
- Fear
- Surprise

## Technologies
- Python
- PyTorch
